# 🐾 Лапка — система приюта для животных

Курсовой проект: веб-приложение для кинолога + мобильное приложение для усыновителя.

## 📦 Что входит

- **Django-сайт** — управление животными и заявками (для кинолога),
  публичный каталог, регистрация и профиль клиента (веб).
- **REST API** — на Django REST Framework с JWT-авторизацией.
- **Flutter-приложение** — мобильный клиент для усыновителей:
  каталог животных, регистрация, вход, профиль, подача заявки.

## 🚀 Технологии

| Часть | Стек |
|---|---|
| Бэкенд | Python 3.13, Django 5+, SQLite |
| API | Django REST Framework, SimpleJWT |
| Фронтенд (веб) | Django Templates, Bootstrap 5 |
| Мобильное | Flutter 3.47, Dart 3.13 |

## ⚙️ Установка и запуск

### 1. Django

```bash
cd shelter
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Открыть: http://127.0.0.1:8000/

### 2. Flutter

```bash
cd mobile_app
flutter pub get
flutter run -d windows
```

## 🌐 API

| Метод | URL | Что делает |
|---|---|---|
| GET | `/api/animals/` | Список животных |
| GET | `/api/animals/<id>/` | Карточка животного |
| POST | `/api/token/` | Получить JWT-токен |
| POST | `/api/register/` | Регистрация клиента |
| GET | `/api/profile/` | Профиль + свои заявки |
| POST | `/api/animals/<id>/apply/` | Подать заявку |
| GET | `/api/applications/` | Все заявки (только кинолог) |

## 🎯 Возможности

### Кинолог
- Просмотр, поиск, сортировка, фильтр по виду
- CRUD карточек животных
- Загрузка фотографий
- Просмотр заявок и смена статуса

### Клиент
- Публичный каталог животных
- Регистрация и вход
- Анкета усыновителя
- Профиль со своими заявками

### Мобильное приложение
- Каталог животных с фото
- Карточка животного
- Регистрация / вход
- Профиль с заявками
- Подача заявки
